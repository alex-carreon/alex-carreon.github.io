**eLikas** is a response to the challenges of urban flooding in the Philippines. It combines crowdsourced reporting with physical IoT sensor data to provide residents with an accurate, real-time map of flood levels and safe evacuation routes.

### Technical Contributions
* **API & Database Design:** Architected a **MariaDB** schema to handle geospatial data (GIS) and high-frequency sensor logs.
* **IoT Integration:** Developed the firmware for **ESP32**-based ultrasonic sensors to push water level data via HTTP.
* **PWA Deployment:** Built a private **Tailscale** network to serve as the project's backbone for all necessary services.
